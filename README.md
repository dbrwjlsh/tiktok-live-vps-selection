## 原生、住宅、双 ISP：套餐名里已经写清楚了

原生 IP 指的是 IP 注册地和服务器所在地一致，TikTok 看到的是一条当地运营商的地址。住宅 IP 更进一步，它来自真实的家庭宽带运营商，而不是机房分配的公网段。双 ISP 则是检测工具里能读出两条运营商属性、带家庭宽带特征。三者可以叠加，WePC 的套餐命名基本能对上这三种属性。

标了“原生家宽”“双 ISP 家宽”的属于住宅属性，比如英国原生家宽 AUD$14.90、韩国双 ISP 家宽 AUD$19.90、马来西亚双 ISP 家宽 AUD$24.90、洛杉矶两条 Cogent 家宽 AUD$12.90。标“原生 IP”却没写家宽的就要小心：英国 TikTok 专线 AUD$10.90 和德国 TikTok 专线 AUD$10.90，官网明确写着“非家宽 IP”；新加坡那条 AUD$16.90 写的是“原生 IDC”，同样不是家宽。

这里是最容易踩的一处：同样叫“英国 TikTok 专线”，AUD$10.90 和 AUD$14.90 差的不是 4 澳元，而是 IP 性质。前者是机房原生 IP，后者是家庭宽带 IP。做直播、尤其是新号起号，差价这点钱通常值得花。

## 中转这件事，比价格更影响体验

买完发现推流一直卡，很多时候不是套餐差，是这条线路本来就要求你自己配一台中转机。

不需要中转的套餐有：洛杉矶 Cogent 9929 家宽直播、洛杉矶 GTT/NTT 216/192、纽约 Cogent 家宽、洛杉矶 Cogent 静态家宽、澳大利亚墨尔本、英国“无需中转直播线路”版、日本“直播无需中转”版。这几条官方都明确标注了免中转。

必须中转的只有西班牙一条，官网用的是“必须”两个字。

建议中转的包括英国原生家宽、法国、阿联酋、加拿大、新西兰、巴西、韩国、新加坡家宽、马来西亚，以及菲律宾的少部分区域。印尼是联通电信需中转、部分移动表现好。

还有一类是特定运营商必须中转：新加坡原生 IDC 的电信用户、德国专线的电信用户。

如果你手头没有现成的中转机，选套餐时把这一项当地址来看，比省下的几澳元重要得多。美区之所以值得优先考虑洛杉矶 9929，很大一部分原因就是它把中转这道工序省掉了。
